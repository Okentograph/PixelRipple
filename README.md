# コンピュータ基礎II 課題1 — 色の波紋

9×9マスのいずれかをクリックすると、その場所に「色の点」が置かれる。
点の色は不透明度100%（純色）で、そこから離れるほど不透明度が下がり、
白いキャンバスが透けて見えるようになる。複数の点を打つと、
色が届く範囲が重なり合った場所で色が混ざる。

同じ点をもう一度クリックすると色が切り替わり、**その瞬間に全マスの色が
計算し直される**ため、常に最新の状態が表示される。

## 遊び方

- マスをクリックすると、そこに色の点が置かれる（**黒→赤→オレンジ→黄色→黄緑→緑→水色→青→紫→茶→白**の順）。
- 同じ点をもう一度クリックすると、色が1つ先に進む。
- 点から離れるほど不透明度が下がる（1マスごとに20%ずつ）。5マス先で不透明度0（白）。
- **最後にクリックした点だけ**は、常に完全にその色のまま。それ以外の点は、後から近くに打たれた点の影響を受けて色が混ざる。
- **🗑️（書き直し）** … すべての点を消して白紙に戻す。

## 課題の4条件との対応

| 条件 | 実装箇所（script.js） |
| --- | --- |
| 1. 図形（面）を描画 | `fillRect()` で正方形を描画 |
| 2. 色を数値で指定 | RGBの数値と不透明度（0〜1の数値）で色を決める |
| 3. 繰り返し + 条件分岐 | 全マスへの二重ループ、`if` による複数の分岐 |
| 4. 乱数（ランダム）を利用 | 混ざった色に `Math.random()` で少しノイズを加える |

## 主な調整パラメータ（script.js 冒頭）

| 定数 | 意味 |
| --- | --- |
| `GRID` | 縦横のマス数（9） |
| `RADIUS` | 色が届く範囲。5マス先で不透明度0になる |
| `NOISE` | 混ざった色に加える乱数の強さ |

## しくみの解説（初学者向け）

1. `pointColor` という**9×9の表（2次元配列）**を用意する。マス目そのままの形で、
   点が無ければ `-1`、点があればその色番号を入れておく。
2. クリックすると、その場所の番号を1つ進める（`pointColor[row][col] = pointColor[row][col] + 1`）。
   点が無い場所は `-1` なので、1を足すとちょうど `0`（黒）から始まる。
3. 毎回のクリックのあと、**81マス全部**について「このマスは何色か」をゼロから
   計算し直す（`draw`）。
4. 1マスの色を決める `colorAt` は、次の考え方で計算する。
   - 白い紙 `[255, 255, 255]` からスタートする。
   - 表の中から点がある場所を順番に探し、そのマスとの距離を測る。
   - 距離が近いほど不透明度が高く（`1 - 距離/5`）、5マス離れると0になる。
   - 点が見つかるたびに、今の色をその点の色へ「不透明度」の分だけ近づける
     （絵の具を少しずつ重ね塗りするイメージ）。
   - 最後に、色が届いたマスにだけ乱数で少しゆらす。
   - ただし、**最後にクリックしたマスだけ**は、この計算をせず必ずそのままの色にする。
